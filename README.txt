EMI Manager - Android Studio project
1. Android Studio > File > Open > select this "EMIManager" folder; wait for Gradle sync.
2. Build > Build Bundle(s) / APK(s) > Build APK(s)  (or press Run with a phone connected).
3. APK: app/build/outputs/apk/debug/app-debug.apk
UI source: app/src/main/assets/index.html (same as EMI_Manager.html).
